# Bank Account Management System

A simple Python project demonstrating **Object-Oriented Programming (OOP)** concepts using a bank account system.

## Features

- Create bank accounts
- Deposit money
- Withdraw money
- Transfer money between accounts
- Check account balance
- Maintain transaction history
- Save account data to a JSON file
- Load saved account data from a JSON file

## Concepts Used

This project demonstrates:

- Classes and Objects
- Constructor (`__init__`)
- Encapsulation
- Methods
- Private/protected-style attributes
- Exception handling
- JSON file handling
- Lists and dictionaries

## Requirements

- Python 3.x

No external libraries are required.
